# 📊 PowerBI Sales Forecasting & Anomaly Detection Dashboard

A Power BI project featuring interactive dashboard for sales analysis, trend forecasting, and anomaly detection.

---

## 📁 Files

- `Sales Forecasting & Anomaly Detection.pbix` — Forecasting & anomaly detection dashboard

---

## 🔍 Dashboard : Sales Forecasting & Anomaly Detection

Key metrics: **Sum of Sales, Sum of Quantity, Sum of Profit**, filterable by Region.

Includes:
- Sales trend over time (by date and by month)
- Sales breakdown by Region and Product (Sankey-style flow)
- Sum of Sales by Region (bar chart)
- Auto-generated insights panel highlighting:
  - Significant sales trend increases/decreases over specific date ranges
  - Sharpest growth periods
  - Detected anomalies in sales data

---

## 🛠️ Tools Used

- **Microsoft Power BI Desktop**
- Built-in Power BI forecasting & anomaly detection visuals

---

## 🚀 How to Use

1. Download and install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free).
2. Clone or download this repository.
3. Open either `.pbix` file directly in Power BI Desktop.
4. Use the filter panes (Region, Product, Category, etc.) to explore the data interactively.

---

## 📌 Notes

- Data used is sample/sales transaction data for demonstration purposes.
- Anomaly detection and trend insights are generated using Power BI's built-in analytics features.
